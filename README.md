# LEM_Pro

**LEM Pro** es la familia tipográfica oficial del **Laboratorio de Experimentación Multimedia (LEM)**, perteneciente a la Facultad de Hábitat de la Universidad Autónoma de San Luis Potosí (UASLP).

Este proyecto dota al laboratorio de una identidad visual propia, diseñada para articular el diseño experimental, la narrativa transmedia, los estudios de la imagen y la tecnología con el diseño gráfico contemporáneo.

## Estructura de la Familia (v1.0.0)
La familia se compone actualmente de **4 estilos** (Upright), optimizados para lectura en pantalla y piezas de experimentación multimedia:

| Peso | Upright | Italic | Weight Class |
| :--- | :---: | :---: | :---: |
| **Light** | ✓ | - | 300 |
| **Regular** | ✓ | - | 400 |
| **SemiBold** | ✓ | - | 600 |
| **ExtraBold** | ✓ | - | 800 |

## Especificaciones Técnicas
* **Formato:** OTF (OpenType Font)
* **Unidades por Em (UPM):** 1024
* **Glifos por fuente:** 954 (Set extendido Pro)
* **Soporte Lingüístico:** Amplia cobertura en lenguas latinas (incluyendo soporte Pro para múltiples caracteres especiales, diacríticos y variantes tipográficas).

## Instalación y Uso
1. Descarga los archivos de la carpeta `builds/otf/proof/`.
2. Instala los estilos en tu sistema operativo.
3. Para asegurar el funcionamiento correcto de la vinculación de estilos (Regular a Bold), se recomienda usar software que soporte *Style Linking*.
